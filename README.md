A tiny program that writes a two-line warning to its past self. Line one warns about one specific moment — signing a lease on a rainy night in March 2019 — and line two traces what that single decision cost: two years of rent that ate half a paycheck, and the savings that were never built. No dependencies, no network, just the text.

## Run it

```sh
node main.ts
```

It validates the text (exactly two lines, one sentence each, at most 280 characters) and writes it to `/output/entry.txt`.
